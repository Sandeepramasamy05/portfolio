# Sandeep's Portfolio

Personal portfolio of **Sandeep Ramasamy**: MSc Software Systems student at CIT, Coimbatore, building full-stack and AI products.

## Features
- Two switchable worlds with a page-turn transition: **Dragon Grove** (green fantasy landscape, flying cartoon dragons) and **Comic Crew** (comic-book page with an original hero team)
- A draggable buddy (**DragonBuddy** / **RoboBuddy**) that introduces the site with its own voice, explains anything you hover or tap, and hides in a screen edge
- Interactive terminal (`help`, `projects`, `skills`, `open docmind`, `theme crew`), Ctrl+K quick menu, project case studies, filters
- Journey shown as a winding path your buddy walks as you scroll
- Toolbox as dragon eggs (Grove) or flip power cards (Crew)
- No build step: a single `index.html` with inline CSS and JS; fonts from Google Fonts

## Run locally
Open `index.html` in a browser, or serve the folder:
```
npx serve .
```

## Deploy with GitHub Pages
Settings → Pages → Deploy from branch → `main` / root.
